# NOCOM project instructions

This overrides the global "push directly to main" rule for this project.

- Still commit every change on its branch.
- I only have read access to the upstream repo, so push branches to the `fork` remote (`waxmotson/NOCOM`) and open the PR against `kay1611178-ux/NOCOM` `main`.
